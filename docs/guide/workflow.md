# 提问工作流（用户视角）

这个仓库的核心循环是：**你提问 → AI 归档 → 站点更新**。你不需要了解任何技术细节，直接在任何设备上向任意 AI 助手（ZCode / Claude / GPT / GLM 等）提问即可——只要它在这个仓库里工作，它就会按 [AGENTS.md](https://github.com/kongchaolaohei/investing-note/blob/main/AGENTS.md) 的流程处理。

## 你提问后，AI 会做什么

1. **回答你的问题**（这是第一位的）。
2. **归档答疑笔记**：在 `docs/qa/年-月/` 下新建一篇记录：问题原文、结论、分析过程。
3. **沉淀词典词条**：如果问题涉及新的指标/概念，在对应模块（A股/港股/通用）新建或更新词条；已有词条则补充内容并标注本次更新来源。
4. **更新索引**：答疑索引、模块词条表、首页"最近更新"。
5. **推送上线**：commit 并 push 到 `main`，约 2~3 分钟后 [站点](https://kongchaolaohei.github.io/investing-note/) 更新。

## 查找旧内容的三种方式

- **搜索**：站点右上角搜索框，支持中文（如搜"商誉"找到资产负债表词条）。
- **字典浏览**：知识字典 → 对应市场模块 → 分类目录。
- **答疑回溯**：每个词条的"相关答疑"区块反向链接到催生它的那次提问；答疑笔记也链接到涉及的词条。

## 财报/业绩公告

把 PDF 交给 AI 并说明公司名称，AI 会：

- 存入 `docs/filings/<公司名>/` 并登记到档案索引；
- 站点上生成下载链接；
- 在你后续针对该财报提问时，补充"快速阅读要点"（关键财务摘要）。

## 小提示

- 问题尽量带上下文（哪家公司、哪个市场、看到了什么数字），归档质量更高。
- 如果某个回答很好，说一句"归档吧"，AI 会把本次讨论整理入库；默认情况下 AI 也会主动归档投资知识类问题。
- 站点是公开的，不要提供个人账户、持仓成本等敏感信息。
