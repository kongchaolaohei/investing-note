# A股三大表总览

上市公司财务报表的核心是三张表，加上所有者权益变动表和附注合称"四表一注"，但分析时最常用的就是三大表：

| 报表 | 回答的问题 | 视角 | 性质 |
|---|---|---|---|
| [资产负债表](balance-sheet.md) | 公司家底如何？资产多少、欠债多少、股东权益多少 | 某一时点的"照片" | 时点数（期末余额） |
| [利润表](income-statement.md) | 这段时间赚了多少？怎么赚的 | 一段时期的"录像" | 时期数（本期发生额） |
| [现金流量表](cash-flow-statement.md) | 真金白银进出多少账 | 一段时期的"录像" | 时期数（收付实现制） |

## 勾稽关系（三表如何连起来）

- 利润表的**净利润**，扣除分红后累积进资产负债表的**未分配利润**（期末 = 期初 + 净利润 - 分红）；
- 现金流量表的**期末现金及现金等价物**，等于资产负债表**货币资金**（口径大体对应）期末减期初；
- 三表在逻辑上必须自洽，勾稽对不上往往意味着口径调整或附注里有故事。

## 在年报里哪里看

A 股年报的**"财务报告"章节**（近年一般为第十一节，以实际目录为准）依次披露：审计报告 → 合并资产负债表 → 母公司资产负债表 → 合并利润表 → 母公司利润表 → 合并现金流量表 → 母公司现金流量表 → 所有者权益变动表 → 附注。

**看合并报表**（反映整个集团），母公司报表仅反映上市主体自身，主要用于看分红能力和与合并报表的差异。

## 分析时的基本顺序建议

1. 先看[资产负债表](balance-sheet.md)摸清家底与杠杆；
2. 再看[利润表](income-statement.md)看盈利结构与质量（警惕非经常性损益）；
3. 用[现金流量表](cash-flow-statement.md)验证利润含金量（净利润 vs 经营现金流）。
