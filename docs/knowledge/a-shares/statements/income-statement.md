# 利润表

## 是什么

反映公司**一段期间**（季度 / 半年 / 年）经营成果的报表，回答"这段时间赚了多少、怎么赚的"。A 股采用**多步式**结构，从收入层层扣减到净利润，本身就是一个分析框架。

## 怎么来的 / 在财报哪里看

- 位置：年报财务报告章节，合并资产负债表之后；季报、半年报、年报均披露。
- 编制：按**权责发生制**——收入在履约时确认、费用与收入配比，不等于收到/付出现金（现金视角看[现金流量表](cash-flow-statement.md)）。

## 关键科目 / 关键要点

多步式主线（自上而下）：

```
营业总收入（营业收入 / 利息收入 / 已赚保费 / 手续费及佣金收入，按行业）
− 营业总成本（营业成本 + 税金及附加 + 销售费用 + 管理费用 + 研发费用 + 财务费用）
+ 其他收益 / 投资收益 / 公允价值变动收益 / 信用减值损失 / 资产减值损失
± 资产处置收益
= 营业利润
+ 营业外收入 − 营业外支出
= 利润总额
− 所得税费用
= 净利润
   ├─ 归属于母公司股东的净利润（归母净利润）★
   └─ 少数股东损益
```

两个衍生口径：

- **扣非归母净利润**：归母净利润扣除非经常性损益（政府补助、处置资产收益、公允价值变动等一次性项目），更接近可持续盈利。
- **基本每股收益（EPS）** = 归母净利润 ÷ 总股本，是估值的分母基础。

## 分析视角

- **毛利率** =（营业收入 − 营业成本）÷ 营业收入：产品竞争力第一指标，看趋势和同业对比。
- **费用率**：销售/管理/研发/财务费用各自占收入比，观察扩张是否以费用失控为代价。
- **非经常性损益**：净利润高增但扣非平平，盈利质量存疑，年报"主要会计数据"部分有专项披露。
- **归母 vs 少数股东损益**：子公司并非 100% 持股时，少数股东分走的部分要剔除。
- **收入确认方式**：附注中收入政策变化（总额法/净额法、时点/时段）可能显著改变收入体量。
- 勾稽验证：净利润扣除分红后累积进[资产负债表](balance-sheet.md)的未分配利润。
