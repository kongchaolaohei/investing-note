# 现金流量表

## 是什么

按**收付实现制**记录一段期间真金白银流进流出的报表，分三大活动：

| 活动 | 典型内容 |
|---|---|
| 经营活动 | 销售收到的现金、支付给职工与供应商的现金、税费——主业造血能力 |
| 投资活动 | 购建固定资产/无形资产、对外股权投资、收回投资与分红——扩张或收缩 |
| 筹资活动 | 借款与偿还、发行股票/债券、分红回购——与资本市场的往来 |

三块净额加汇率影响 = 现金及现金等价物净增加额，期末余额对应[资产负债表](balance-sheet.md)的货币资金。

## 怎么来的 / 在财报哪里看

- 位置：年报财务报告章节，利润表之后；主表用**直接法**（按现金收支性质列示）。
- **补充资料**（附注内）用**间接法**把净利润调节为经营现金流：加回折旧摊销、资产减值等非现金项目，加减应收/存货/应付的变动——这是排查"利润为什么没变成钱"的地图。

## 关键科目 / 关键要点

- **经营活动现金流量净额**：最核心的数字，持续为负说明主业失血。
- **销售商品、提供劳务收到的现金**：与营业收入对比（含税口径 ≈ 收入 × 1.13 左右），长期显著偏低说明收入挂账多。
- **购建固定资产、无形资产和其他长期资产支付的现金**：资本开支（CapEx），重资产公司的生命线。
- **分配股利、利润或偿付利息支付的现金**：分红意愿与付息压力。
- 自由现金流（常用口径）= 经营现金流净额 − 资本开支。

## 分析视角

- **净现比** = 经营现金流净额 ÷ 净利润：长期 ≥ 1 较健康，持续大幅低于 1 要追问应收/存货去向。
- **三活动净额组合**（+ 为净流入）：
    - 经营 +，投资 −，筹资 −：成熟造血型，还能还债分红（典型白马）；
    - 经营 +，投资 −，筹资 +：成长扩张型，融资支撑扩张；
    - 经营 −，投资 −，筹资 +：烧钱依赖型，盯紧筹资能力；
    - 经营 −，投资 +，筹资 +：变卖家产型，警惕。
- **利润与现金流的背离**是财务造假的经典信号：收入利润高增而经营现金流持续萎缩。
- 间接法补充资料里"应收账款增加、存货增加"吞噬现金的幅度，常藏着你应该问的下一个问题。
