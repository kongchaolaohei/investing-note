# A股模块

A 股上市公司财务与分析知识：三大表、财务指标、信息披露规则。会计准则以**中国企业会计准则（CAS）**为准，披露规则以**证监会与交易所（沪深北交易所）**要求为准。

## 分类

- [三大表](statements/index.md) —— 资产负债表、利润表、现金流量表及勾稽关系
- [其他指标](indicators/index.md) —— 盈利 / 偿债 / 营运 / 现金流 / 估值指标
