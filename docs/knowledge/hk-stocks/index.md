# 港股模块

港股上市公司财务与分析知识：财报结构、指标、披露规则。会计准则以**香港财务报告准则（HKFRS）**为准（与国际 IFRS 高度趋同），披露规则以**港交所（HKEX）上市规则**及证券及期货事务监察委员会（SFC）要求为准。

## 分类

- [财报结构](statements/index.md) —— 港股年报组成、报表名称与 A 股的术语对照
- [其他指标](indicators/index.md) —— 港股特有或口径不同的指标（股息率、AH 溢价…）
