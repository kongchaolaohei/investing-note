# 港股财报结构

## 是什么

港股上市公司遵循**香港财务报告准则（HKFRS）**编制财务报表，报表名称、披露节奏和科目叫法与 A 股（中国准则 CAS）有明显差异。读懂港股财报的第一步是对上"翻译表"。

## 怎么来的 / 在财报哪里看

港股年报（Annual Report）的典型结构：

1. 公司资料 / 目录
2. **主席报告 & 管理层讨论与分析（MD&A）**——业务回顾与展望，阅读价值最高的部分之一
3. 企业管治报告（Corporate Governance Report）
4. **独立核数师（审计师）报告**
5. **综合财务报表**：
    - 综合损益及其他全面收益表（Consolidated Statement of Profit or Loss and Other Comprehensive Income）
    - 综合财务状况表（Consolidated Statement of Financial Position）
    - 综合现金流量表（Consolidated Statement of Cash Flows）
    - 综合权益变动表
6. 附注（Notes）——收入明细、分部信息（Segment information）等关键细节都在这里

披露节奏（主板）：财年结束后约 **3 个月内**发年报，中期报告在半年结后 **2 个月内**；此外有季度性"业绩公告"（盈利警告/正面盈利预喜按需披露）。A 股对比：年报 4 月 30 日前、一季报 4 月内、半年报 8 月底前、三季报 10 月底前。

## 关键科目 / 关键要点：A 股 ↔ 港股术语对照

| A 股（CAS） | 港股（HKFRS） | 备注 |
|---|---|---|
| 资产负债表 | 综合财务状况表 | Statement of Financial Position |
| 利润表 | 综合损益及其他全面收益表 | 全面收益概念更突出 |
| 归母净利润 | 股东应占溢利 | Profit attributable to owners |
| 少数股东损益 | 非控股权益应占溢利 | |
| 每股收益 | 每股基本盈利 / 摊薄盈利 | Basic / Diluted EPS |
| 股本 + 资本公积 | 股本 + 股份溢价 | 储备（Reserves）体系更细 |
| 未分配利润 | 保留溢利 / 累计亏损 | Retained profits/deficits |
| 应收账款 | 贸易应收款项 | Trade receivables |
| 存货 | 存货 / 库存 | Inventories |
| 营业收入 | 收益 | Revenue/turnover |
| 销售费用 | 分销及销售开支 | Distribution and selling expenses |
| 管理费用 | 行政开支 | Administrative expenses |
| 财务费用 | 融资成本 | Finance costs |
| 审计报告 | 核数师报告 | "核数"即审计 |

## 分析视角

- **报表范围**：港股用"综合（Consolidated）"字样表示合并报表，读法与 A 股合并报表一致。
- **分部信息（Segment）**：多元化集团（如中国食品这类母公司下多业务线）看分部收入/溢利，比只看整体更接近真相。
- **"其他全面收益"**：汇率折算、金融资产公允价值变动等不计入当期损益的项目，A股在"其他综合收益"同样存在，只是港股呈现方式更靠前。
- **业绩公告 vs 年报**：港股"业绩公告"（Results Announcement）先于年报发布、篇幅短，只有关键数字；深度分析仍以年报附注为准。
- 准则差异会导致同一集团 A/H 两地报表数字不完全相同（如油气、金融工具准则差异），对比 A+H 公司两套报表时先看"准则差异调节表"。
